# 背包问题实验室

CS0502 课堂交互演示：比较按价值/重量排序的贪心策略和 0/1 背包动态规划。

默认容量为 10 kg。四件宝物依次为 `(重量, 价值)`：国王的古董 `(5, 100)`、皇后的妆盒 `(2, 40)`、教皇的皇冠 `(3, 51)`、公主的项链 `(2, 35)`。性价比贪心先选前两件，再选项链，得到 9 kg、175 点；皇冠放不下。动态规划使用

```text
dp[i][c] = dp[i - 1][c]                                  if weight[i] > c
dp[i][c] = max(dp[i - 1][c], value[i] + dp[i - 1][c - weight[i]]) otherwise
```

逐格填充 4 × 11 个状态，最优组合为古董、妆盒和皇冠，重量 10 kg、价值 191 点。页面为纯 HTML/CSS/JavaScript，无构建步骤。
