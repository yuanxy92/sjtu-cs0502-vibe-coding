同一份数据，8 句话，8 张图第 1 页：把数据交给 agent，让它按你的提示词把图画出来

过去这件事的流程是：想清楚要画什么 → 查数据 → 打开软件 → 调样式 → 导出。 现在前两步之间可以插一句话：告诉 agent 你想看什么，它把图画出来，还能把代码给你看。

① 提示词 → 生成结果（本页） ② 同一份数据 → 可交互界面

数据说明：以下全部为教学模拟数据（虚构），无随机源，数值可手工核对；不指向任何真实疫情。 本页的图由页内的一个离线解析器生成（相当于把一次 LLM 回答固化成规则）；现场可以让 agent 按同样的提示词重跑。 本页不提供"改提示词再生成"的入口——离线页面里跑不到模型，要改一句话请交给现场的真 agent。

1agent 拿到的数据：一张表

一份 CSV，几张固定表。下面就是 agent 手上全部的东西——它没有别的信息， 所谓"画图"就是：从这几张表里取数、选一个图型、画出来。

表 3｜另外 5 张小表

它们各自独立，也都是 agent 能直接用的：

  • 区 × 日 矩阵：12 区 × 7 天（04-10 ~ 04-16）的阳性率，取自表 1 的区级明细
  • 年龄构成：9 个年龄段的人数
  • 住院天数：15 个天数档的例数（含 1 例 28 天的离群点）
  • 流入矩阵：8 个来源省 → 6 个目的区的人数
  • 症状词：20 个词的词频 + 25 组共现关系

2这一轮运行的日志

下面 8 条提示词被真的跑了一遍：每条 → 解析成规格 → 生成代码 → 执行代码 → 出图。 用时是这次运行的实测值。

#提示词识别出的图型用时结果

③ 提示词 → 生成结果

每张卡片 = 一句提示词 + agent 对它的理解 + 跑出来的图 + 它写的那段代码。 展开「代码」看 agent 是怎么写的； 图看着小？点一下图就全屏放大（放大视图里图、规格、代码在一起，Esc 关闭）。

④ 同一份数据，换四种问法

换提示词不是只能换图型，也可以换问题。数据一个字没动，问题变了，图就得重画。

这一页要说的只有一句：在 AI 之前，"把数据变成一张图"的主要成本是想清楚画什么；现在这句话可以直接说给机器听。 下一页把同一份数据做成一个能筛、能钻、能联动的界面——那是另一种交付物。

数据为教学模拟数据（虚构）；本页提示词 → 代码 → 图的链路为离线可复现实现。
