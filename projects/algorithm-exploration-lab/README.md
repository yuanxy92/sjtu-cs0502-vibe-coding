# 算法探索实验室

面向 CS0502《计算机科学导论》的静态交互页面，当前聚焦图探索、DFS、BFS 与最短路径演示。

## 打开页面

直接打开 `index.html`，或在课程网站中进入数据结构项目，选择“打开算法探索实验室”。页面不依赖构建工具或第三方算法库。

## 课堂投影可读性

本平台面向教室投影和远距离阅读，界面文字采用较大字号；图例、步骤记录、边权、表格和按钮等辅助文字也保持至少 14px。窄屏通过换行和滚动适应内容，不通过缩小字号来塞入更多信息。后续新增页面请沿用这一可读性要求。

## 课堂操作

- “图探索”使用课件第 20–23 页的 A–F 无向图；逐步比较 DFS 递归栈与回溯过程，以及 BFS 队列与边数距离。
- “最短路径”使用课件第 40–47 页的带权有向图；Dijkstra 从 S 到 t 的最短路径为 S → c → d → e → t，总权重为 12。也可切换 A* 比较 g(n) 与 g(n)+h(n)。
- 使用“上一步”“下一步”、播放控制或进度点逐帧观察；图、伪代码、操作说明与数据结构同步更新。
- 可查看邻接表和邻接矩阵，也可以编辑当前图的边列表。
