SQL 输入

支持 SELECT [DISTINCT] 列|* FROM 表[,表… | NATURAL JOIN 表] [WHERE 条件]；条件支持 = != < <= > >=、AND / OR 和表别名。字符串用单引号 '数据库'，中文输入法打出的 “数据库” 同样可用。多表用逗号连接时，引擎会按 FROM 顺序逐表相乘、并用 WHERE 里只涉及已连接表的条件提前过滤（谓词下推）。
