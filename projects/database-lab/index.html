SQL 输入

支持 SELECT 列|* FROM 表[,表… | NATURAL JOIN 表] [WHERE 条件]；条件支持 = != < <= > >=、AND / OR 和表别名。多表用逗号连接时，引擎会先做笛卡尔积再用 WHERE 过滤——这正是复杂度暴涨的原因。
