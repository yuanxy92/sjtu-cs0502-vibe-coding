# CS0502 · Artificial Intelligence Foundations

Students must choose exactly **one** of the three fixed projects below. There is no open-topic option. Use an AI coding agent, but develop your own prompts, technical approach, tests, and iteration process.

| Project | Topic | Package contents |
| --- | --- | --- |
| A | Retail customer segmentation and insights | Brief and Online Retail data |
| B | Smartphone activity recognition: MLP vs. 1D CNN | Brief and UCI HAR data |
| C | MiniMind practice | Three MiniMind tasks; complete any two |

## Common submission requirements

Submit a complete project folder or ZIP containing source code, a runnable application where applicable, a README, a short recording of the work running, and an illustrated report describing data, method, results, AI-agent iteration, problems, and at least one limitation or failure case.

Read the brief in the folder for your selected project before starting. Follow the licenses and classroom-use rules for all supplied data and models.
