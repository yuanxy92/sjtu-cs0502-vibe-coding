# Project C · MiniMind Practice

Project C contains three independent MiniMind tasks. Complete **any two** tasks. For every task, provide a successful run, evidence showing raw model output, and a short analysis. Installation screenshots without actual model output do not count.

| Task | Topic | Suggested difficulty |
| --- | --- | --- |
| 1 | Base MiniMind-3 deployment | ★ |
| 2 | MiniMind-O multimodal deployment | ★★ |
| 3 | LoRA news-topic fine-tuning | ★★★ |

Read [Task Brief](Task-Brief.md), then choose two tasks. Use [Submission Checklist](Submission-Checklist.md) and [Report Template](Report-Template.md) for every completed task.

This folder should be placed alongside `minimind/`, `minimind-o-source/`, and `minimind-o/` in the same `MiniLLM` working directory. Model weights are not duplicated in this package.
