# Submission Checklist

Create one folder for every completed MiniMind task, for example `Task-1-Name`. Each folder must contain:

- `README.md`: environment, launch command, and reproduction steps;
- `evidence/`: terminal or WebUI screenshots showing raw model output;
- `outputs/`: text outputs, metrics JSON, or necessary logs;
- `report.md`: a short report based on the included template.

## Additional requirements for task 3

- Never publish the full TNEWS raw data in a public repository.
- Submit the training configuration, best-checkpoint filename, and evaluation metrics. LoRA weights may be submitted privately only if the course platform permits it.
- State whether strict accuracy and normalized accuracy are both reported, and define each metric.
