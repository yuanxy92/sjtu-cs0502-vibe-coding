# MiniMind Task Brief

## Task 1 · Base MiniMind-3 Deployment

Run the official MiniMind-3 without the course news LoRA. Complete at least three different input types, including one prompt that requires exactly one word or category as output. Preserve every raw model output.

See [Task 1 instructions](Task-1-Base-MiniMind-3/README.md).

## Task 2 · MiniMind-O Multimodal Deployment

Start the MiniMind-O local WebUI and complete interactions in at least two input modalities. Text plus image is recommended; audio input or speech output may be added when available.

Submit a WebUI screenshot, the input files used, and at least one raw model output for each modality.

See [Task 2 instructions](Task-2-MiniMind-O-Multimodal/README.md).

## Task 3 · LoRA News-Topic Fine-Tuning

Build a finance/sports/gaming news-topic classifier LoRA on MiniMind-3. Pass the data check and submit the training configuration, best validation checkpoint, final locked-test report, and at least ten prediction examples. The final test set may be used only after the training plan is locked.

See [Task 3 instructions](Task-3-LoRA-News-Topic-Fine-Tuning/README.md).
