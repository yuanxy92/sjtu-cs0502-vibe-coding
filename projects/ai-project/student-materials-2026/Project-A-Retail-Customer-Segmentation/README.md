# Project A · Retail Customer Segmentation and Insights

Use the included Online Retail transaction data to build a Python + HTML application.

## Core requirements

1. Clean the transaction data and construct customer RFM features: recency, frequency, and monetary value.
2. Cluster customers with K-Means and display segment size, RFM characteristics, and customer or segment distributions.
3. Write a data-grounded profile and one business recommendation for each segment.
4. Compare one changed setting, such as the number of clusters, standardization, or a cleaning rule, and explain the difference.

## Bonus ideas

Compare several K values with a justified selection; add filters, a detail panel, chart export, automatic insight summaries, or a sensible clustering comparison.

## Data

Extract `data/CS2026-route-a-retail-data.zip` before use. Keep the included source note with your project and follow its data-use terms.
