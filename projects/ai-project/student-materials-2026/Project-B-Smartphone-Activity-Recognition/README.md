# Project B · Smartphone Activity Recognition: MLP vs. 1D CNN

Use the included UCI HAR data to build a Python + HTML activity-recognition application.

## Core requirements

1. Train an MLP using the prepared 561-dimensional feature vectors.
2. Train a 1D CNN using the raw `128 × 9` inertial-sensor time series.
3. On the same test split, compare accuracy, confusion matrices, and one easily confused activity pair.
4. Show test-sample curves, ground truth, both model predictions, and confidence in the application; explain the strengths and limitations of the two approaches.

## Bonus ideas

Compare two or more network configurations and analyze parameters, training time, accuracy, or confusion changes. You may also add error-sample visualization, class filtering, an error library, or result export.

## Data

Extract `data/CS2026-route-b-har-data.zip` before use. Keep the included source note with your project and follow its data-use terms.
