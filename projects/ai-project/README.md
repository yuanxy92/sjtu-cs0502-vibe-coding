# CS0502 · Foundations of Artificial Intelligence / 人工智能基础

## 中文

本资料只提供人工智能基础项目的公开要求。教师会分别提供每个项目所需的数据、模型权重或使用说明；学生不应等待或索取完整的 AI 提示词，而应自行规划与 AI coding agent 的协作过程。

阅读 `AI_PROJECT_BRIEF.md`，选择 A、B 或 C 中的一个项目。项目 C 使用 MiniMind 学生任务材料包，并要求在其三个独立任务中任选两个完成。提交时包含完整源代码、可运行 App、录屏、README 与图文报告。请遵守教师提供数据与模型的许可证和课堂使用约定；尤其不要将任务 3 的完整 TNEWS 原始数据公开上传。

## English

This material contains only the public requirements for the Foundations of Artificial Intelligence project. The instructor will provide the data, model weights, or usage notes needed for each project. Do not expect or request a complete AI prompt; plan your own collaboration with an AI coding agent.

Read `AI_PROJECT_BRIEF.md` and choose one project—A, B, or C. Project C uses the MiniMind student task package and requires any two of its three independent tasks. Submit complete source code, a runnable app, a recording, a README, and an illustrated report. Follow the licenses and classroom-use expectations for all instructor-provided data and models; in particular, never publicly upload the full TNEWS raw data from task 3.
