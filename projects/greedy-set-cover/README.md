# 路由器覆盖实验

面向 CS0502《计算机科学导论》的交互式贪心集合覆盖演示。页面无需构建工具、后端或第三方算法库，直接打开 `index.html` 即可使用。

## 课堂操作

- 点击八台候选路由器，构造学生自己的方案；校园地图会高亮相应建筑，并标出覆盖关系。
- 每台候选路由器都有部署成本（演示点数），可以切换“最少台数”和“最低总成本”两个目标。
- 候选列表会随贪心步骤显示本轮各设备还能新增覆盖的区域数；成本模式还会列出本轮新增覆盖 / 固定成本的得分。已经选中的设备显示它当时实际带来的新增覆盖。
- “最少台数”模式每轮选择能覆盖最多未覆盖区域的路由器；“最低总成本”模式每轮计算固定成本 / 本轮新增区域数，选择“点/区”最低的路由器。使用“上一步”“下一步”和“重置”控制进度。
- 得分并列时优先选择成本较低的设备，再按候选列表顺序处理。在“最少台数”模式下，R2 的覆盖数最大（6 个），贪心先选 R2，再选 R3、R6、R1，用 4 台、25 点覆盖全部区域。切到“最低总成本”模式后，贪心依次选 R3、R6、R1，用 3 台、12 点。
- 页面穷举全部 256 种设备组合，提供精确最优基准。当前数据的最少台数是 3，最低总成本是 12 点；因此数量贪心在本例未达到最优，成本贪心则达到了最低成本。
- 决策表显示每步新增覆盖、本轮单位区域成本（点/区）、累计成本和剩余区域。算法未达到最优时，会直接显示与精确基准的差距。

## 区域与覆盖关系

区域集合为 `{A, B, C, D, E, F, G, H, I, J, K, L}`。候选路由器的覆盖集合为：

- R1: `{A, B, C, D}`
- R2: `{A, B, E, F, I, J}`
- R3: `{E, F, G, H}`
- R4: `{A, C, E, G, I}`
- R5: `{B, D, F, H, J}`
- R6: `{I, J, K, L}`
- R7: `{A, B, C, G}`
- R8: `{D, E, I, K}`

成本点数：R1=5、R2=13、R3=3、R4=6、R5=11、R6=4、R7=7、R8=9。这些是课堂演示用的相对部署成本，不代表真实设备价格。八台设备的初始成本/覆盖区域比分别为 1.25、2.17、0.75、1.20、2.20、1.00、1.75、2.25，彼此不同。

课堂讨论重点是：贪心策略每一步只看局部收益；眼前覆盖最多的 R2 留下了三个彼此分散的缺口，导致总共需要 4 台，而精确最优方案只需 3 台。局部最优选择不保证全局最优。
