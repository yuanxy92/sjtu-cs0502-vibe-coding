# 数字签名实验室

课堂演示用单页：输入一段文字或一个小文件，算 MD5 散列；发送者 Alice 用自己的私钥给散列签名；消息和签名打成一个包，用接收者 Bob 的公钥逐块加密；Bob 用自己的私钥解密，再重算散列、用 Alice 的公钥验签。另有“篡改一个字节”演示，直接看到验签失败。

## 打开方式

- 课程站入口：展开“信息安全 · 密码学 / RSA 实验室”卡片，点“打开数字签名实验室（MD5 + RSA）”。
- 直接双击 `index.html`，无需联网、无需安装依赖。
- 或者在本目录运行 `python3 -m http.server 8000`，访问 <http://localhost:8000>。
- 单文件离线版：`node build.cjs` 生成 `dist/index.html` 和 `../exports/signature-lab.html`。

## 页面结构

| 步骤 | 内容 |
| --- | --- |
| ① 输入与散列 | 文字或文件二选一（文件最大 8 KB）；UTF-8 字节数、MD5 的 128 位结果；可展开看补位与分组；按钮“改一个字节再算一次”演示雪崩效应 |
| ② 私钥签名 | `s = H^D_A mod N_A`，H 是 16 字节散列，签名固定 64 字节；对比 Alice 公钥（验签）与私钥（签名） |
| ③ 公钥加密 | 把 4 字节长度头、消息、64 字节签名拼成整包，每 63 字节一块，用 Bob 公钥逐块加密成 64 字节密文；显示第一块的明文/密文，可展开全部块 |
| ④ 私钥解密 | `m_i = c_i^D_B mod N_B`，按长度头拆出消息和签名；提供“篡改消息/篡改签名/恢复原样”课堂控制 |
| ⑤ 验签 | 重算 `H′ = MD5(收到的消息)`，用 Alice 公钥恢复 `H_sig = s^E_A mod N_A`，比较两者；通过/失败给出对应解释 |

## 课堂脚本（约 12 分钟）

1. **区分三件事**：散列保护“内容有没有变”，签名证明“是谁发的”，公钥加密保证“路上有没有人看见”。本页按这三件事依次做一遍。
2. **输入与散列**：默认消息“转账 1000 元给 Bob，周五下午三点前到账。”是 55 字节，MD5 为 `d40fe8b8ee15d9a73276e0b68b47d4ed`。点“改一个字节再算一次”，32 个十六进制字符几乎全变——散列对内容极其敏感。
3. **散列不是加密**：MD5 没有钥匙、不可逆，任何人拿到消息都能算；它只能发现“内容变了”，不能证明“谁发的”。
4. **私钥签名**：Alice 对 16 字节散列做 `s = H^D_A mod N_A`，得到 64 字节签名。强调这不是加密消息：任何人用 Alice 公钥都能把签名还原成散列，这正是验签需要的。
5. **整包加密**：只加密消息、不加密签名，攻击者就能替换消息；所以把消息和签名一起打包，用 Bob 的公钥逐块加密。演示消息是 55 字节，整包 123 字节，切成 2 块；第一块密文是 64 字节（128 个十六进制字符）。
6. **Bob 解密**：只有 Bob 的私钥能还原整包；解出消息和签名。强调“能解开”只说明 Bob 收到了，不代表是 Alice 发的——任何人都能用 Bob 的公钥加密假消息。
7. **验签**：Bob 重算收到的消息的散列 H′，再用 Alice 公钥从签名恢复 H_sig；两者一致才算通过。验签只需要“消息 + 签名 + Alice 公钥”，不需要 Alice 的私钥，也不需要提前保存原文。
8. **篡改演示**：在第 4 步点“篡改消息中的一个字节”（默认消息里的 `1000` 会变成 `1001`），再到第 5 步验签，H′ 与 H_sig 不一致，验签失败；恢复原样后再验，重新通过。也可以只改签名，观察恢复出的散列变成乱码。
9. **收尾**：散列谁都能算，单靠散列挡不住伪造；是“私钥签名 + 公钥验签”把内容和身份绑定。真实系统用 SHA-256、2048 位以上 RSA、PSS 填充和证书；长文件用混合加密。MD5 和 512 位无填充 RSA 只用于课堂演示。

## 页面里的固定数值

```text
默认消息：转账 1000 元给 Bob，周五下午三点前到账。
UTF-8：55 字节
MD5：d40fe8b8ee15d9a73276e0b68b47d4ed（16 字节 / 32 个十六进制字符）
Alice 签名：64 字节（128 个十六进制字符）
整包：4 + 55 + 64 = 123 字节
分块：每块 63 字节 → 2 块，每块密文 64 字节
```

## 实现说明

- MD5 按 RFC 1321 实现，小端字、64 轮；用 Node `crypto.createHash('md5')` 交叉验证。
- 两对固定 512 位 RSA 演示钥匙，`E = 65537`，直接写在 `signature.js` 里。
- 采用教材式 RSA：没有 OAEP/PSS 填充，直接对 63 字节块做模幂；`N` 是 512 位，所以每块最多 63 字节。
- 整包格式：4 字节大端消息长度 + 消息字节 + 64 字节签名；解密后按长度头拆分。
- 演示上限 8 KB。真实 RSA 不适合直接加密长文件，实际系统用 AES 加密正文、RSA 加密 AES 密钥。
- 所有计算都在浏览器本地完成，文件不会上传。

## 安全边界

这是课堂模型，不是可用的密码库：MD5 已被王小云团队攻破碰撞，512 位 RSA 也可以被分解；没有填充的教材 RSA 还不具备真实签名方案的安全性。真实系统请使用 SHA-256/384、2048 位以上密钥、PSS/OAEP 和可信证书。
