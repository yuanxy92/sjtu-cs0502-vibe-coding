# Contributing

Thank you for helping improve CS0502.

- Open an issue for broken links, factual corrections, accessibility problems, or proposed changes to a project brief.
- Keep pull requests focused and explain how you verified the change.
- Do not add student submissions, private course information, credentials, copyrighted material without permission, or large generated build artifacts.
- Starter materials intentionally omit some required algorithms or features. Preserve those teaching boundaries unless an assignment update is explicitly being made.

For changes that alter grading, required deliverables, or project scope, please start with an issue so the teaching team can discuss the change.
